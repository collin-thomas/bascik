HTML components without a JavaScript framework.

Bascik is a static site generator. Write reusable HTML components, get scoped CSS and scoped JS for free.

Get Started → GitHub

Features

Everything in one place

Each feature is a building block. Use all of them or just the ones you need.

Slots

Default & Named

Pass inner content into components. Named slots target specific zones. Fallback content supported.

Props

Component Props

Inject text values into templates via data-bascik-prop-* attributes at usage time.

CSS

Scoped Styles

Class names, element selectors, @media, and @keyframes are all automatically scoped.

JS

Scoped JavaScript

DOM selectors in component scripts are rewritten to match scoped IDs and class names.

Config

Configuration

Override defaults via bascik.config.js. Toggle scoping, obfuscation, minification, and more.

Start

Getting Started

Install, create your first component, and run the dev server in under five minutes.

Philosophy

Why Bascik

The guiding principle: use what already exists. No runtime, no framework, no invented syntax. And why that makes Bascik the right tool for AI too.

Reference

Scoping Compatibility

A complete audit of which CSS selectors and JavaScript DOM patterns are scoped, partially supported, or intentionally unsupported.

Migration

Migration Guides

Moving from React, Next.js, Eleventy, or Astro. Concept mapping and worked examples — designed for humans and AI alike.
