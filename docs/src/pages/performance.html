Technique Summary

Performance

srcset + sizes

Serve appropriately sized images per device. Saves hundreds of kilobytes on mobile.

Performance

loading="lazy"

Defer off-screen images and iframes. Reduces initial page weight and improves LCP.

Performance

rel="preload"

Fetch critical assets (hero image, fonts) before the browser would otherwise discover them.

Performance

rel="prefetch"

Prime the cache for the user's next likely navigation during idle time.

Performance

rel="preconnect"

Open connections to critical third-party origins before they are needed.

Performance

defer / async

Never block HTML parsing with scripts. Use defer for app code, async for analytics.

Performance

width + height on images

Reserve layout space before images load. Eliminates Cumulative Layout Shift.

Performance

font-display: swap

Show text immediately with a fallback font. Swap when the custom font arrives.

Accessibility

Semantic HTML

Use <header>, <nav>, <main>, <footer>. Landmark roles for free.

Accessibility

Skip link

Let keyboard users bypass navigation with a visually-hidden-until-focused anchor.

Accessibility

alt text

Every meaningful image needs a descriptive alt. Decorative images get alt="".

SEO

Unique <title> per page

The single highest-impact SEO signal. Bascik makes this natural — one file, one title.

SEO

meta description

Controls the snippet shown in search results. Keep it under 160 characters.

SEO

Canonical URL

Prevents duplicate-content penalties when content is accessible at multiple URLs.

SEO

Open Graph tags

Controls title, description, and image when a page is shared on social platforms.

Best Practices

HTTPS everywhere

Bascik's dev server uses HTTP/2 with a self-signed cert. Deploy behind HTTPS in production.
