Command Line Interface (CLI)

Bascik features a simple, fast, and highly informative CLI for both development and production building.

Commands

Bascik is controlled via two primary commands. In most projects, these are mapped to scripts in your package.json:

bascik (Dev Mode)

Starts the incremental transpiler, generates local SSL/TLS development certificates, launches the built-in HTTP/2 secure server at https://localhost:8443, and watches for files changes.

bascik # or yarn dev

bascik --build (Production Build)

Runs a one-time build. Transpiles and optimizes all pages and assets directly to the configured output directory (defaults to dist/), applying any overrides configured in buildOverrideConfig. Ideal for CI/CD pipelines and static hosting deployments.

bascik --build # or yarn build

Development Workflow & Output

The Bascik CLI keeps you informed of everything happening under the hood without cluttering your terminal.

Starting the Server

On initial startup, Bascik compiles all of your pages, setups the secure socket context, and starts listening:

Generated self-signed certificate for the development server Server running at https://localhost:8443 transpiled: pages/getting-started.html transpiled: pages/index.html transpiled: pages/about.html ✓ 3 pages transpiled in 45ms

File Watcher Events

When you edit or add resources inside your source directories, Bascik selectively transpiles only the affected files to make updates instantaneous:

  • Modifying Pages: Editing src/pages/about.html triggers incremental transpilation of just that page: transpiled: pages/about.html
  • Modifying Components: Modifying src/components/site-nav.html triggers selective transpilation. Bascik knows which pages use this component and only rebuilds those pages: transpiled: pages/index.html transpiled: pages/about.html
  • Asset Syncing: Adding or updating static assets (like a custom CSS or image file) copies them immediately: copied: /Users/collin/github/bascik/docs/src/pages/css/custom.css
  • Deleting Pages: Deleting a page removes its compiled counterpart from the dist/ directory automatically: deleted file: /Users/collin/github/bascik/docs/src/pages/old-page.html

Error Log Reporting

If there's ever a problem during compilation or build-time script execution, Bascik logs clear context highlighting exactly where and why the error happened, keeping your dev server running:

Component Transpilation Error

[bascik] Transpilation failed for component <site-nav> during css-scoping in "pages/about.html" at (line 22, column 8) Defined in component template: "components/site-nav/site-nav.html" Error: ParseError: CSS Selector is invalid or could not be parsed.

Build Script Error

[bascik] build script error in "pages/index.html" at (line 12, column 5): ReferenceError: marked is not defined
