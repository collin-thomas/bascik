## Head Components

Components work inside `<head>`:

```html
<!-- src/components/site-meta.html -->
<meta name="viewport" content="width=device-width, initial-scale=1.0" />
<meta name="description" content="My site" />
```

```html
<head>
  <title>Home</title>
  <site-meta></site-meta>
</head>
```
