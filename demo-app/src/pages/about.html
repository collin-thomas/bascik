About

Why Bascik?

Most web frameworks require you to learn their system, their templating language, their way of doing things. Bascik takes the opposite approach: write plain HTML, reference components by tag name, and let the build step handle the rest.

Goal

Zero JavaScript by default

Bascik adds no client-side JavaScript to your pages. Every script that appears in the output was written by you.

Approach

HTML-first

Components are plain .html files. CSS is plain .css. Bascik is a fancy find-and-replace, not a runtime.

Learning curve

MDN is the docs

You already know the language. Bascik adheres to web standards so every reference you need is already on MDN.

Output

Static HTML

The build output is a dist/ directory of plain HTML, CSS, and assets. Deploy to any static host — S3, Netlify, Cloudflare Pages, etc.
