Default Slot

Pass inner content to a component via <slot-component> or the newer data-bascik-slot.

Usage

<tag-a> <tag-b> <p>This is slot content</p> </tag-b> </tag-a>

Output

This is slot content

Slot Fallback Content

If no inner content is passed, the component's own default is shown.

Component template

<!-- my-card.html --> <div class="card"> <slot-component> Default card text </slot-component> </div>

Usage — no slot content

<my-card></my-card>

Output (fallback renders)

Named Slots

Pass content to specific zones in a component using data-bascik-slot="name".

Component template

<footer> <hr /> <!-- default slot --> <slot-component></slot-component> <!-- named slot --> <div data-bascik-slot="my-named-slot"></div> </footer>

my-footer rendered

Component Props

Inject values into a component template using data-bascik-prop-* attributes.

Component template

<!-- feature-card.html --> <div class="fcard"> <p class="fcard-label" data-bascik-prop-label></p> <h3 data-bascik-prop-title></h3> <p data-bascik-prop-desc></p> </div>

Usage

<feature-card data-bascik-prop-label="New" data-bascik-prop-title="My Feature" data-bascik-prop-desc="Works great."> </feature-card>

Output

Nested Components

Components can be infinitely nested. Transpilation recurses until all custom tags are replaced.

Usage

<tag-a> <tag-b> <tag-c></tag-c> <tag-d></tag-d> </tag-b> </tag-a>

Output

Attribute Inheritance

Non-data-bascik-* attributes on the usage tag are automatically merged onto the component's root element — class names are appended, others are added if not already present.

Usage — pass class + aria-label

<my-self-closing class="extra-class" aria-label="example"> </my-self-closing>

Output — attrs merged onto root <p>

Inspect element to see class and aria-label on the rendered <p>.

Build-time Scripts

Tag a script with data-bascik-build to run it at transpile time. The script's stdout is injected in place of the tag — no client-side JavaScript required.

Build script source

<script data-bascik-build> console.log('<span class="badge">Built at ' + new Date().toISOString() + '</span>'); </script>

Key rules

  • CWD is the project root — paths are relative to the project root
  • Top-level import and await are supported
  • Output via console.log() or process.stdout.write()
  • Output can contain component tags — resolved after the script runs
  • On error, the tag is replaced with an empty string and a warning is logged

data-bascik-dev — dev-only script (stripped in production builds)
