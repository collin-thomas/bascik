JavaScript Libraries

Bascik adds zero JavaScript — but you can bring your own. Any CDN-delivered library works alongside Bascik's build-time component system. This page demonstrates petite-vue, a ~5 KB reactive library for progressive enhancement.

Reactive Counter (petite-vue)

Each Bascik component gets its own isolated v-scope state. Two instances of the same component on the same page run completely independently.

v-counter.html — component source

<div v-cloak v-scope="{ count: 0 }"> {{ count }} <button @click="count++">inc</button> </div>

Page head — petite-vue loaded once

<script src="https://unpkg.com/petite-vue" defer init ></script>

Live Filter (petite-vue)

v-model and v-for work exactly as in Vue. Filter a list in real time without writing a single line of manual DOM code.

Component source

<div v-scope="{ query: '', items: ['Astro','Eleventy','Hugo', 'Jekyll','Next.js','Nuxt', 'SvelteKit','Vite'] }"> <input type="search" v-model="query" placeholder="Filter…" /> <ul> <template v-for="item in items.filter(i => i.toLowerCase() .includes(query.toLowerCase()) )"> <li>{{ item }}</li> </template> </ul> </div>

Show / Hide (petite-vue)

v-show and v-if work for toggling visibility — no JavaScript event listeners to write by hand.

Component source

<div v-scope="{ open: false }"> <button @click="open = !open"> {{ open ? 'Hide' : 'Show' }} details </button> <div v-show="open"> <p>Hidden content revealed.</p> </div> </div>

Live

This content was hidden. Revealed with v-show — no manual DOM code needed.

Alpine.js (alternative)

Alpine.js follows the same pattern with slightly different attribute names. Replace v-scope with x-data and swap the CDN URL.

<!-- Alpine.js version of the same component --> <div x-data="{ open: false }"> <button @click="open = !open">Toggle details</button> <p x-show="open">Hidden content.</p> </div> <script src="https://unpkg.com/alpinejs" defer></script>

Libraries That Use IDs (Chart.js, etc.)

Bascik rewrites id attributes and matching getElementById calls at build time — so libraries that mount to a DOM element by ID work without any special handling.

<canvas id="my-chart"></canvas> <script src="https://cdn.jsdelivr.net/npm/chart.js" defer></script> <script> // Bascik rewrites "my-chart" to its scoped id at build time — // the compiled ID in the canvas and getElementById call will match. document.addEventListener('DOMContentLoaded', () => { const ctx = document.getElementById('my-chart'); new Chart(ctx, { type: 'bar', data: { labels: ['Jan', 'Feb', 'Mar'], datasets: [{ data: [10, 20, 15] }] } }); }); </script>
