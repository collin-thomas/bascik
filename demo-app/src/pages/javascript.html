Feature Demo

Scoped JavaScript

Bascik rewrites DOM selector calls inside component <script> tags to match the scoped IDs and class names. Multiple instances of the same component work independently.

getElementById & querySelector

References to IDs in document.getElementById(), querySelector("#id"), and querySelectorAll("#id") are rewritten to use the scoped attribute value.

my-btn.html (source)

<button id="my-btn">Click</button> <script> document.getElementById("my-btn") .addEventListener("click", () => { alert("clicked!"); }); </script>

Compiled — ID rewritten per instance

<button id="bascik__my-btn__a1b2__my-btn">Click</button> <script> (function() { document.getElementById("bascik__my-btn__a1b2__my-btn") .addEventListener("click", () => { alert("clicked!"); }); })(); </script>

getElementsByClassName

Class names referenced in getElementsByClassName() and CSS-selector forms like querySelector(".class") are rewritten to match the scoped HTML class names.

Source — class selector in script

<ul class="nav-links">...</ul> <script> const links = document.getElementsByClassName("nav-links"); // or: querySelector(".nav-links") </script>

Compiled — class name scoped

<ul class="bascik__comp__x1__nav-links">...</ul> <script> (function() { const links = document.getElementsByClassName( "bascik__comp__x1__nav-links" ); })(); </script>

Script Isolation (IIFE)

Each component's script block is wrapped in an IIFE to prevent variable leaks between components or repeated usage on the same page.

Source

<script> const count = 0; // ... </script>

Compiled — isolated in IIFE

<script> (function() { const count = 0; // ... })(); </script>

Build-only Scripts

Tag scripts with data-bascik-build to execute them at transpile time — their stdout is injected in place of the tag.

Source

<!-- Only in production build --> <script data-bascik-build> analytics.init("UA-XXXX"); </script>

Result

The data-bascik-build script runs at transpile time and its stdout is injected in place of the tag. The attribute is removed from the final HTML.
