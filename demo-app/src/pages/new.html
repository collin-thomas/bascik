Build-time Scripts

Tag a script with data-bascik-build to run it at transpile time. Whatever the script writes to stdout is injected into the page in place of the tag — no client-side JavaScript required.

Build script — reads content/sample-post.md at build time

<script data-bascik-build> import { readFile } from 'node:fs/promises'; const md = await readFile('./content/sample-post.md', 'utf8'); // Lightweight inline Markdown -> HTML converter function mdToHtml(text) { text = text.replace(/^### (.+)$/gm, '<h3>$1</h3>'); text = text.replace(/^## (.+)$/gm, '<h2>$1</h2>'); text = text.replace(/^# (.+)$/gm, '<h1>$1</h1>'); text = text.replace(/\*\*(.+?)\*\*/g, '<strong>$1</strong>'); text = text.replace(/`([^`]+)`/g, '<code>$1</code>'); text = text.replace(/\[([^\]]+)\]\(([^)]+)\)/g, '<a href="$2">$1</a>'); return text.split(/\n\n+/).map(block => { block = block.trim(); if (!block || /^<h[1-6]/.test(block)) return block; return '<p>' + block.replace(/\n/g, ' ') + '</p>'; }).join('\n'); } console.log(mdToHtml(md)); </script>

Key rules

  • CWD is the project root — paths are relative to the project root
  • Top-level import and await are supported
  • Output via console.log() or process.stdout.write()
  • Output can contain component tags — resolved after the script runs
