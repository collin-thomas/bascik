Feature Demo

Scoped Styles

Bascik automatically namespaces your component CSS — class names, element selectors, @media, and @keyframes are all scoped to each component instance.

Class Scoping

CSS class names in a component's .css file are prefixed with a unique instance ID so they can never conflict with other components or global styles.

custom-nav.css (source)

.navigation ul { list-style-type: none; } .navigation ul li a { padding: 8px; }

Compiled output

.bascik__custom-nav__a1b2c3__navigation ul { list-style-type: none; } .bascik__custom-nav__a1b2c3__navigation ul li a { padding: 8px; }

Element Selector Scoping

Bare element selectors like p {} are converted to class selectors and injected onto matching elements so they only apply within the component.

styled-element-test.css (source)

p { text-decoration: #d3ff8d wavy underline; display: block; }

Compiled — class injected on every <p>

.bascik__styled-element-test__x1__el__p { text-decoration: #d3ff8d wavy underline; }

Live — only <p> tags inside the component are affected

This <p> is outside the component — no wavy underline.

@media & @keyframes Scoping

Media queries and keyframe animation names are also scoped so components don't conflict with each other's animations.

custom-nav.css (source)

@keyframes rotateLogo { from { transform: rotateY(-40deg); } to { transform: rotateY(40deg); } } .home.logo { animation: rotateLogo 2s infinite alternate; } @media (max-width: 600px) { .home.logo { background: #d3ff8d; } }
